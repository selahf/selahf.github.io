# Academic Portfolio: Selah Frederickson

This is a personal academic and technical portfolio for Selah
Frederickson.

## About

This portfolio is created to showcase work at the intersection of
computer science, sociology, research, data science, and writing.

I am an aspiring researcher aiming to learn more about topics such as
data visualization, human-computer interaction, educational technology, 
artificial intelligence, and computational social science.

- `experience.html`: page for experience
- `index.html`: home page
- `projects.html`: page for projects
