## Project Structure

This project has the following structure:
```
assets/
    icons/
    images/
        profile/
        projects/

css/
    components.css
    pages.css
    theme.css

js/
    main.js

about.html
contact.html
experience.html
index.html
projects.html
```

Each directory and file has a distinctive purpose:
- `assets/`: images and other assets
- `css/`: stylesheets
- `js/`: interaction
- `about.html`: about page
- `contact.html`: contact information
- `experience.html`: page for experience
- `index.html`: home page
- `projects.html`: page for projects
